03 Identity Layer: DID Resolver & did:evrc Method

⑥ Resolver  +  ⑦ did:evrc — EveryCRED DID Method

Decentralized Identity foundation — every Issuer & Holder gets a sovereign identity

did:evrc:<identifier>
W3C DID Core 1.0
DID Resolver Service
did:evrc: resolution endpoint
Resolves did:evrc:<id> to a DID Document. Exposes Universal Resolver-compatible HTTP endpoint. Used by Verifier to validate issuer DID during credential check. Supports DID Document caching.
Universal Resolver compat DID Document cache HTTP GET resolution
did:evrc DID Method
EveryCRED Native Identity
Proprietary DID method registered under EveryCRED. Each Issuer org gets a did:evrc: identifier on creation. DID Document contains public key material for credential signing & verification. Blockchain-anchored for trust.
Auto-generated on Issuer create Ed25519 keypair Blockchain anchored
DID Document
W3C DID Core spec
Contains: DID subject, verification methods (public keys), authentication, assertionMethod, service endpoints. Used to verify credential proof signatures.
verificationMethod assertionMethod serviceEndpoint
DID Format
did:evrc:<unique-identifier>

05 Key End-to-End Flows
Component Interaction Flows
Credential Issuance
Issuer (DCS) → creates Record → triggers issuance → DCS signs with did:evrc key → anchors hash on blockchain → notifies Holder by email → Holder views in Wallet
Workflow Data Collection
DCS Workflow → assigns stage to Contributor → POSTs request to Contributor Service → Contributor fills fields → images → S3 → submission → DCS advances to next stage
Credential Verification
Verifier (employer) → hits Public Verifier API with UUID → Verifier calls Resolver to validate did:evrc issuer DID → checks signature, revocation, blockchain hash → returns 6-point result
Holder Wallet Flow
Holder logs into Wallet Web App → Angular AuthGuard → fetch credentials from DCS API → KYC via SurePass (IN: DigiLocker) → share credential URL → Verifier resolves via Verifier service
DID Lifecycle
Issuer created in DCS → auto-generate did:evrc identifier → store in Issuer record → DID Document published to Resolver registry → blockchain-anchored → available for resolution globally
SaaS API Integration
3rd-party client → authenticates with API key → SaaS Service enforces rate limits & tenant isolation → proxies to DCS modules → returns standardized response envelope
